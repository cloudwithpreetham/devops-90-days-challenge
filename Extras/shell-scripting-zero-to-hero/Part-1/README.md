## Essential Linux Commands

| Command | Purpose                        |
| ------- | ------------------------------ |
| `ls`    | List files and directories     |
| `touch` | Create a new empty file        |
| `cat`   | Read/display file contents     |
| `chmod` | Manage file/script permissions |

## Shell Scripting Basics

- **Shebang (`#!/bin/bash`)**: The first line of a shell script, telling the system which interpreter to use to run it
- **sh vs. bash vs. dash**: Different shell interpreters with subtle differences in features and compatibility — important to understand which one a script is actually targeting

---

## Automation in DevOps

A significant portion of the video focuses on **why** DevOps engineers rely on shell scripts, including:

- Infrastructure maintenance
- Configuration management
- Monitoring node health across thousands of virtual machines

At scale, manually checking servers one by one isn't feasible — shell scripts are what make consistent, repeatable operations across large fleets of machines possible.

---

## System Monitoring

Commands introduced for checking system resources:

- **CPU and RAM usage** monitoring basics
- **`top`** — highlighted specifically for live process monitoring

---

## Key Takeaways

- Shell scripting turns repetitive manual Linux tasks into automated, repeatable operations
- The shebang line and understanding sh/bash/dash differences matter once scripts move between environments
- DevOps automation at scale (config management, monitoring thousands of VMs) is only practical because of scripting
- `top` and similar monitoring commands are the first line of defense for troubleshooting resource issues
